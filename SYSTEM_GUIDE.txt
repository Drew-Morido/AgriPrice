================================================================================
  1. ANO ANG AgriPricePH?
================================================================================

AgriPricePH ay isang rice price prediction system para sa Pilipinas. Kinokolekta
nito ang historical at live data (presyo ng bigas, diesel, USD/PHP, ulan, stock),
iniimbak sa SQLite database, tina-train ang LSTM (o fallback MLP) model, at
nagbibigay ng 2-araw na forecast sa web dashboard.

Mga pangunahing layunin:
  - I-visualize ang presyo ng bigas at related factors (charts)
  - Mag-scrape ng bagong data mula sa DA, fuel site, at exchange API
  - Mag-train ng time-series model batay sa merged daily data
  - Mag-predict ng Local Well-Milled price para sa Day 1 at Day 2

================================================================================
  5. DATA PIPELINE — PAGSASAMA BAGO MAG-TRAIN
================================================================================

Hakbang 1: LOAD (load_merged_frame)

  - Kukunin ang bawat table mula sa SQLite
  - Rice: pinagsasama ang retail_prices + WS_rice_price (concat, groupby Date, mean)
  - Fuel: fuel_history.Diesel + WS_fuel.RON_95
  - Exchange: usd_php_rates + WS_currency.USD_to_PHP
  - Weather: weather_data."Rainfall (mm)"
  - Stock: rice_stock (kasama sa merge pero HINDI kasama sa 5 ML features)

Hakbang 2: MERGE BY DATE

  df = rice
  for each (fuel, usd, weather, stock):
      df = outer_merge(df, extra, on="Date")

  df = sort by Date
  df = ffill().bfill()    # punan ang missing values mula sa nakaraan/susunod

Hakbang 3: CLEAN

  - Coerce to numeric, fillna(0) para sa feature columns
  - dropna kung walang target
  - filter: locWellMilled > 0 lang


================================================================================
  6. TRAINING — BUONG COMPUTATION (STEP BY STEP)
================================================================================

Ito ang pinakamahalagang bahagi: eksaktong matematika at proseso mula raw data
hanggang saved model.


--------------------------------------------------------------------------------
  6.1 NORMALIZATION — MinMaxScaler
--------------------------------------------------------------------------------

Bawat feature column (5 columns) ay i-scale sa range [0, 1]:

  Formula (per column j):
    scaled[i,j] = (value[i,j] - min_j) / (max_j - min_j)

  Sa code:
    scaler = MinMaxScaler()
    scaled = scaler.fit_transform(df[features].values)

  Bakit: Para pantay ang magnitude ng presyo (40-60 PHP), fuel, exchange (50+),
         at rainfall — mas stable ang neural network training.


--------------------------------------------------------------------------------
  6.2 SEQUENCE BUILDING — make_sequences()
--------------------------------------------------------------------------------

Gamit ang scaled matrix (N rows × 5 features), bumubuo ng sliding windows:

  Para sa bawat index i mula 0 hanggang N - SEQ_LEN - HORIZON:

    X[i] = scaled[i : i+30]           # shape: (30, 5) — 30 araw × 5 features
    y[i] = scaled[i+30 : i+32, target_idx]   # 2 values — target column lang

  Halimbawa kung SEQ_LEN=30, HORIZON=2, target_idx=0 (locWellMilled):
    - Input: araw 1-30 ng lahat ng features
    - Output: araw 31 at 32 na locWellMilled (scaled)

  Bilang ng samples:
    num_sequences = N - SEQ_LEN - HORIZON + 1
    Minimum required: 50 sequences (kung < 50, ERROR at exit)

  Minimum data rows sa DB:
    N >= 30 + 2 + 50 - 1 = 81 araw (praktikal: mas marami para sa train/test split)


--------------------------------------------------------------------------------
  6.3 TRAIN / TEST SPLIT
--------------------------------------------------------------------------------

  split = int(len(X) * 0.8)    # 80% train, 20% test (time-ordered, HINDI shuffle)

  X_train = X[0:split]
  X_test  = X[split:]
  y_train = y[0:split]
  y_test  = y[split:]

  Halimbawa (mula sa meta.json):
    train_samples = 3304
    test_samples  = 826
    Total sequences ≈ 4130


--------------------------------------------------------------------------------
  6.4 MODEL A — TensorFlow LSTM (preferred kung may tensorflow)
--------------------------------------------------------------------------------

Architecture (Sequential):

  Layer 1: LSTM(64, return_sequences=True)  input=(30, 5)
  Layer 2: Dropout(0.2)
  Layer 3: LSTM(32, return_sequences=False)
  Layer 4: Dropout(0.2)
  Layer 5: Dense(16, relu)
  Layer 6: Dense(2)   # HORIZON = 2 outputs

Compile:
  optimizer = "adam"
  loss      = "mse"     # Mean Squared Error
  metrics   = ["mae"]   # Mean Absolute Error (scaled space)

Training loop (bawat epoch, bawat batch):

  LOSS (MSE) — average sa training batch:
    L = (1/n) * Σ (y_true - y_pred)²

  MAE (metric) — average absolute error sa scaled target:
    MAE = (1/n) * Σ |y_true - y_pred|

  Validation: same formulas sa X_test, y_test

  Hyperparameters:
    EPOCHS     = 100 (o AGRIPRICE_EPOCHS env var)
    BATCH_SIZE = 32
    EarlyStopping: patience=15, monitor=val_loss, restore_best_weights=True
    ModelCheckpoint: save best lstm_model.keras kapag bumaba ang val_loss

  Adam optimizer: adaptive learning rate (default Keras settings)


--------------------------------------------------------------------------------
  6.5 MODEL B — sklearn MLPRegressor (fallback kung walang TensorFlow)
--------------------------------------------------------------------------------

  Input flatten:
    X_flat = X.reshape(n_samples, 30*5) = (n_samples, 150)

  Architecture:
    hidden_layer_sizes = (128, 64, 32)
    max_iter = EPOCHS (100)
    early_stopping = True, validation_fraction = 0.2

  Training:
    mlp.fit(X_flat_train, y_train)

  Loss (internal): sklearn's squared loss sa scaled y
  Validation loss (printed per epoch):
    val_loss = mean((pred_test - y_test)²)
    mae      = mean(|pred_test - y_test|)


--------------------------------------------------------------------------------
  6.6 METRICS SA REAL PESO (PHP/kg) — Pag-convert mula scaled
--------------------------------------------------------------------------------

Ang y_true at y_pred ay nasa scaled space pa. Para sa interpretable error:

  Para sa MinMaxScaler sa target column (index = target_idx):
    scale_j = scaler.scale_[target_idx]
    min_j   = scaler.min_[target_idx]

  Inverse (mula scaled value p back to peso):
    price_peso = (scaled_p - min_j) / scale_j

  MAE sa Peso (ginagamit sa meta.json):
    mae_peso = mean( | (y_true - y_pred) / scale_j | )

    Equivalent: mean absolute error sa original PHP/kg units

  RMSE sa Peso:
    rmse_peso = sqrt( mean( ((y_true - y_pred) / scale_j)² ) )

  Test Loss (scaled MSE):
    test_loss = mean((y_true - y_pred)²)   # sa scaled space


--------------------------------------------------------------------------------
  6.7 ACCURACY PERCENTAGE (estimated)
--------------------------------------------------------------------------------

  avg_price = mean ng actual locWellMilled sa buong dataset
  accuracy = max(0, min(99.9, 100 - (mae_peso / max(avg_price, 1) * 100)))

  Halimbawa:
    mae_peso = 0.2739 PHP/kg
    avg_price ≈ 44 PHP/kg (hal.)
    accuracy ≈ 100 - (0.2739/44*100) ≈ 99.38%

  NOTE: Ito ay simplified accuracy metric para sa UI, hindi formal R².

================================================================================
  7. PREDICTION (INFERENCE) — COMPUTATION
================================================================================

Pagkatapos mag-train, ang predict.py ang tumatakbo sa GET /api/predictions:

Hakbang 1: Load scaler + meta + merged dataframe (same pipeline as training)

Hakbang 2: Transform features
  scaled = scaler.transform(df[features])   # gamit ang FIT ng training, hindi bagong fit

Hakbang 3: Kukunin ang huling window
  window = scaled[-30:].reshape(1, 30, 5)   # huling 30 araw

Hakbang 4: Model forward pass
  TensorFlow: pred_scaled = model.predict(window)[0]   # 2 values
  sklearn:    pred_scaled = mlp.predict(window.flatten())[0]

Hakbang 5: Inverse scale → presyo sa PHP/kg
  price_day_k = (pred_scaled[k] - min_j) / scale_j   para k = 0, 1

Hakbang 6: Forecast dates
  anchor = petsa ngayon (date.today())
  Day 1 = anchor + 1 araw
  Day 2 = anchor + 2 araw

Hakbang 7: Change at confidence
  change[i] = price[i] - previous_price
  confidence[i] = clamp(0.65, 0.98, 1.0 - (mae_peso / max(price,1) * 0.5))

Response JSON: forecast[], current_prices{}, metrics{}, history{labels, values}

================================================================================
  13. FORMULA SUMMARY (QUICK REFERENCE)
================================================================================

  MinMax scale:     x' = (x - min) / (max - min)

  Sequence X:       scaled[t-30 : t]     (30 days × 5 features)
  Sequence y:       scaled[t : t+2, target_col]   (2 days target)

  Train/test:       80% / 20% chronological split

  LSTM loss:        MSE = mean((y - ŷ)²)
  LSTM metric:      MAE = mean(|y - ŷ|)   [scaled]

  MAE peso:         mean(|(y - ŷ) / scale_target|)
  RMSE peso:        sqrt(mean(((y - ŷ) / scale_target)²))

  Accuracy %:       100 - (mae_peso / avg_price × 100), capped 0–99.9

  Inverse predict:  price = (scaled_pred - min) / scale

  Forecast dates:   Day_k = today + k days  (k = 1, 2)
