8) FIX — Keras/TensorFlow version mismatch breaking Predictions (model/predict.py, admin/js/dashboard.js, requirements.txt)
--------------------------------------------------------------------------------
- Problem: after a git pull, the Predictions dashboard could fail and show
  raw internal Keras error text instead of forecasts.
- Fix: a failed model load is now logged server-side and the app falls back
  to the MLP model / trend estimate automatically instead of crashing; the
  dashboard shortens/escapes any error text instead of dumping it raw.
- Prevention: TensorFlow install docs now pin an exact version
  (tensorflow==2.20.0) so everyone's Keras build matches the committed
  model files. One-time action per machine:
      py -3.13 -m pip install tensorflow==2.20.0
